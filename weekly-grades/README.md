# تقييمي الأسبوعي 🏆

تطبيق ويب عربي في ملف واحد (`index.html`) لمتابعة المهام اليومية: الطفل يعلّم مهمته، والمشرف يعتمدها، والنقاط تتحول لمستوى أسبوعي (S، A، B، C، D) له جائزة. فيه كمان متجر مكافآت إضافية، وحسابات متعددة، وإحصائيات وإنجازات، ولعبة «الصقر الطائر».

**الرابط:** https://strangerr07.github.io/my-habits/weekly-grades/

## ملاحظات
- تقدّم الأطفال ينحفظ في متصفح الجهاز نفسه، مو على GitHub. عشان تحفظه أو تنقله لجهاز ثاني، استخدم «💾 نسخة احتياطية» داخل التطبيق.
- أول مرة تضغط «🔒 المشرف» تختار رمز المشرف (4 أرقام). الرمز قفل بسيط يمنع التعديل بالخطأ، وليس حماية أمنية.
- أي تعديل على `index.html` في هذا المجلد ينشره GitHub Pages تلقائيًا خلال دقيقة تقريبًا، وكل نسخة سابقة تبقى محفوظة في سجل المستودع.
